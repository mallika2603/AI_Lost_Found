# 🔎 AI Lost & Found Matcher

An intelligent Lost and Found management system that helps users report lost and found items and identify possible matches.

## Features

- User Registration and Login
- Report Lost Items
- Report Found Items
- Upload Item Images
- SQLite Database
- View Personal Reports
- Possible Lost and Found Matches
- Match Score based on item details
- Match Details and Confirmation

## Technologies Used

- Python
- Streamlit
- SQLAlchemy
- SQLite
- Pandas
- NumPy
- Pillow
